
# 💻 Portfolio professionnel — Léa Lacroix

Bienvenue sur mon portfolio professionnel !

Ce projet a pour objectif de présenter mon parcours scolaire,
mes compétences informatiques, mes projets ainsi que mes expériences
professionnelles dans le domaine du développement informatique.

---

## 👩‍💻 À propos

Je suis actuellement étudiante en deuxième année de
**BTS Services Informatiques aux Organisations (SIO)**,
option **Solutions Logicielles et Applications Métiers (SLAM)**.

Je développe mes compétences dans plusieurs langages et technologies :

- HTML
- CSS
- JavaScript
- PHP
- C#

---

## 🎯 Objectifs du portfolio

Ce portfolio a été conçu afin de :

- Présenter mon parcours et ma formation.
- Mettre en valeur mes compétences techniques.
- Présenter les projets réalisés durant ma formation.
- Mettre à disposition mes rapports de stage.
- Regrouper mes formations et certifications.
- Faciliter la consultation de mes documents professionnels.
