Projet scolaire

Fast-Resto

Développement d'une application en C# reposant sur l'architecture MVC.

Présentation du projet

Fast-Resto est un projet développé en C# dans le cadre de ma formation BTS SIO. Il utilise l'architecture MVC (Modèle-Vue-Contrôleur) afin de structurer l'application.

Objectifs

Mettre en pratique le langage C# et comprendre l'organisation d'une application selon le modèle MVC.

Technologies utilisées

C# MVC

Travail réalisé

Je détaillerai ici les fonctionnalités développées, les parties de l'architecture MVC sur lesquelles j'ai travaillé et les difficultés rencontrées.
